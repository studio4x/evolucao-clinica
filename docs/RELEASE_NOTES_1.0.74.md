# Notas da versão 1.0.74

Data: 06/08/2026  
Android: 1.0.74 (versionCode 74)  
Build web: v1.10.722

## Novidades e correções

- Adicionada reprodução nativa para áudios compartilhados pelo WhatsApp quando o player do navegador do aparelho não suporta a prévia Ogg/Opus.
- O controle alternativo permite reproduzir, pausar, acompanhar a duração e avançar ou retroceder no áudio antes do processamento.
- O arquivo original continua sendo usado no processamento da evolução, sem conversão ou perda de qualidade.
