# Notas da versão 1.0.76

Data: 06/08/2026
Android: 1.0.76 (versionCode 76)
Build web: v1.10.729

## Novidades e correções

- Corrigido o retorno da autenticação do Google durante o processamento de áudios compartilhados pelo WhatsApp.
- A conexão com o Google agora é renovada preventivamente antes de iniciar o processamento.
- Eliminados avisos duplicados de autenticação na página de Áudio Recebido.
- A seleção do paciente, template, data e hora é preservada durante a renovação da conexão.
